# 🤖 Machine Learning and Deep Learning Projects

Welcome to my portfolio of end-to-end machine learning and deep learning projects. Each project in this repository demonstrates practical applications of data science techniques, including data preprocessing, model training, evaluation, and visualization.

## 📁 Project List

| Project No. | Project Title                             | Description                                              |
|-------------|-------------------------------------------|----------------------------------------------------------|
| 1️⃣          | [Car Purchase Amount Prediction](./CarPurchaseAmount) | Predict how much a customer is willing to spend on a car using ANN. |
| 2️⃣          | [CIFAR-10 Image Classification](./Cifar10Classification) | Classify images using Convolutional Neural Networks.     |
| 3️⃣          | [Chicago Crime Forecasting](./ChicagoCrimeForecasting) | Time series crime prediction using Facebook Prophet.     |
| 4️⃣          | [Avocado Price Forecasting](./AvocadoForecasting) | Forecast avocado prices using time series analysis.      |
| 5️⃣          | [Traffic Sign Recognition](./TrafficSignsClassification) | LeNet-based CNN for road sign classification.            |
| 6️⃣          | [Email Spam Classifier](./EmailSpamClassifier) | Classify spam vs ham using Naive Bayes.                  |
| 7️⃣          | [Yelp Reviews Sentiment Classifier](./YelpReviewsClassifier) | Classify positive/negative reviews using NLP.            |
| 8️⃣          | [Movie Recommender System](./MovieRecommender) | Recommend movies using collaborative filtering.          |
